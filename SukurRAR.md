# SukurRAR

Архиватор с шифрованием и проверкой файлов через VirusTotal.
Фоновая служба-сторож и графический интерфейс.

## Возможности
- Запаковка папок и файлов в ZIP с шифрованием AES-256
  (надёжный пароль генерируется автоматически и хранится
  в защищённом хранилище пользователя — Windows DPAPI)
- Дополнительно: лёгкий режим (старый ZipCrypto) для совместимости
  со старыми программами. Слабый, только для временных архивов.
- Распаковка любых ZIP-архивов: обычных, ZipCrypto и AES — по паролю.
  Без пароля зашифрованный архив не открывается: программа не
  подбирает и не обходит пароли.
- Проверка любого файла по базе 70+ антивирусов (VirusTotal API):
  считается SHA-256 и сверяется с базой. Содержимое файлов не
  отправляется никуда — только хэш.
- Служба-сторож: следит за папкой «Загрузки», новые файлы
  автоматически проверяются в VirusTotal, зловреды уходят в карантин.
- Автоматические зашифрованные бэкапы выбранных папок по расписанию.
- Защита файловой системы: при попытке заархивировать, изменить или
  распаковать что-либо в C:\Windows, Program Files, ProgramData
  программа показывает «Ошибка безопасности» и отменяет действие.
  Это штатная функция защиты, а не баг.
- При первом запуске программа предлагает скачать официальный
  WinRAR с сайта разработчика, если пользователю неудобно.

## Установка
pip install pyzipper requests pywin32

## Запуск
python sukur_service.py install   — поставить автозапуск
python sukur_service.py run       — запустить службу вручную
python sukur_service.py pack <путь>          — зашифрованный бэкап сейчас
python sukur_service.py unpack <архив> <куда> — распаковка по паролю

## Конфиденциальность
В VirusTotal отправляется только SHA-256-хэш файла. Пароли хранятся
локально, зашифрованными ключом текущего пользователя Windows,
и никуда не передаются.

## Альтернатива
Если SukurRAR покажется неудобным, официальный WinRAR можно скачать
с сайта разработчика: https://www.win-rar.com
